# Báo cáo vấn đề bảo mật

Không gửi target binary, database IDA, credentials, private keys, local config hoặc dữ liệu dự án nhạy cảm trong issue công khai.

Nếu phát hiện lỗi khiến broker/tool vượt scope, lộ secret, chấp nhận receipt sai target/state hoặc làm sai chain of custody, hãy báo riêng cho maintainer qua kênh liên hệ bảo mật được hiển thị trên GitHub profile của repository. Chỉ cung cấp reproduction tối thiểu đã loại bỏ dữ liệu nhạy cảm.

Các prompt/protocol trong repository là hướng dẫn thiết kế, không thay thế enforcement trong code hoặc sandbox.
