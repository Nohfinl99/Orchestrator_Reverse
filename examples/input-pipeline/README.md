# Request mẫu

[request.json](request.json) là input synthetic để chuẩn bị kế hoạch đọc nguồn, không phải target, kết quả benchmark hoặc authority record. [Hướng dẫn CLI](../../docs/guides/local-input-pipeline.md) có lệnh chạy, exit states, resume/proposal và giới hạn. Giữ runtime outputs ngoài repository public.
